    Rule lifecycle

    Earned, watched,
    and revocable.

    Rules are data, not code. They start in shadow, and a rule that stops performing is demoted back to the LLM.

    What just happened?+

    The system first checked whether it already knew how to handle this failure. If a validated rule existed, it used the rule instead of calling the LLM. If no rule matched, the LLM handled the ambiguous case. Successful behavior can later become a deterministic rule.

    Either way, the action went through the same safety checks before anything happened, and the result was written to a ledger.
